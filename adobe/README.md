# Adobe Express Work Samples

This folder contains projects created using Adobe Express for MIS 561 Data Visualization at the University of Arizona.

## 1. Data Storytelling Infographic

**Client:** Bear Down Bank  
**Consulting Firm:** Clearpoint Analytics

Created a data-driven infographic analyzing Bear Down Bank's contactless card adoption, card expiration patterns, and modernization opportunities. The infographic highlights key findings and recommendations to support card replacement decisions.

[View Data Storytelling Infographic (PDF)](shah-data-storytelling.pdf)

## 2. Product Pitch with Generative AI

**Client:** Bear Down Bank  
**Consulting Firm:** Clearpoint Analytics

Developed a six-slide executive presentation proposing a six-week engagement to create a prioritized contactless card modernization strategy. The pitch uses portfolio data to identify modernization opportunities and outlines the proposed approach, project timeline, deliverables, and approval request.

[View Product Pitch Presentation (PDF)](shah-product-pitch.pdf)
